# Изменения

## 1.0.0 — технический прототип (локальная сборка)

- Первый самостоятельный Fabric-проект для Minecraft 1.21.11 / Java 21.
- Одноразовая тестовая площадка, Гатс как игрок и временная модель Гриффита.
- Серверные удар, защита, уклонение, читаемый цикл противника и ограниченная продолжительность дуэли.
- Техническая постановка перехода к каноническому поражению, очистка после завершения/отмены.
- Заменяемые клавиши, тесты правил и инструкция dev-запуска.

Ограничения и порядок проверки: [боевой стенд](docs/COMBAT_PROTOTYPE.md). Это не выпуск полной кампании и не опубликованный релиз.
