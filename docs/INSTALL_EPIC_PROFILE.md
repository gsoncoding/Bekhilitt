# Установка отдельного Bekhilitt Epic-профиля

Этот пакет — экспериментальная версия первого эпизода, а не полная кампания.
Инструкция не объявляет весь игровой QA завершённым: фактические проверки и
ограничения перечислены в отчёте, приложенном к конкретной сборке.

## 1. Новый профиль, без переноса старых миров

Нужны **Minecraft Java Edition 1.21.1**, **NeoForge 21.1.219**, **Java 21**
и собственный JAR Bekhilitt из этого пакета. Minecraft 1.21.1 и 1.21.11 — разные
версии. Fabric-сборка 1.1.0 остаётся отдельной.

1. Создайте в своём лаунчере **новую установку** с собственной пустой игровой
   папкой, например `Bekhilitt-Epic-1.21.1`. Не используйте папку старого профиля
   или общий `mods`. Проверьте поле игровой папки перед первым запуском.
2. Установите NeoForge **21.1.219 для 1.21.1** через официальный установщик либо
   штатное управление версиями лаунчера. Не выбирайте автоматически «последнюю»
   версию. [Официальная инструкция NeoForge](https://docs.neoforged.net/user/docs/).
3. Выберите Java 21 в настройках именно нового профиля. Для разработки нужен
   полный JDK 21; для игры достаточно совместимого runtime Java 21.
4. Добавьте в JVM-аргументы нового профиля `-Dbekhilitt.dev=true`. Это отдельный
   явный допуск к экспериментальному эпизоду; без него команда запуска откажет.
   Не заменяйте остальные рабочие аргументы лаунчера и не меняйте глобальные настройки.
5. В `mods` новой папки поместите **обычный собственный JAR Bekhilitt** из пакета,
   не `-sources.jar` и не JAR старой Fabric-версии. Его точное имя и контрольную
   сумму берите из сопроводительного списка файлов сборки.

**Не открывайте, не копируйте и не понижайте до 1.21.1 старые миры 1.21.11.**
Миграция миров не предусмотрена. Старый профиль и сохранения оставьте нетронутыми.
Не ставьте в новый профиль дополнительные боевые моды, шейдеры или неизвестные
сборки до проверки базовой конфигурации.

## 2. Официальные зависимости отдельно

`DEPENDENCIES.json` — закреплённые версии, имена, размер и SHA-256 внешних JAR.
В пользовательском пакете **нет перепакованных Epic Fight/Explorify assets** и
нет встроенной копии их JAR. Загрузка идёт с официального хоста автора/площадки.

- Обязательно: Epic Fight **21.17.3.1**, NeoForge-вариант для **1.21.1**,
  [CurseForge file 8175609](https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod/files/8175609).
- Необязательный экспериментальный worldgen-профиль: Terralith **2.5.8**,
  [точная версия MuJMtPGQ](https://modrinth.com/datapack/terralith/version/MuJMtPGQ),
  и Explorify **1.6.5**, [точная версия CuBdAr31](https://modrinth.com/datapack/explorify/version/CuBdAr31).
  Добавляйте их **до создания нового мира**. Не меняйте набор генерации посреди
  прохождения. Это окружение, а не новые главы или гарантированные сюжетные постройки.

### Проверяемый загрузчик

Нужен Python **3.9+**, без сторонних Python-пакетов. Из распакованного пакета
выполните, заменив путь на `mods` **нового** профиля:

```sh
python3 scripts/fetch-official-mods.py --mods-dir "/полный/путь/Bekhilitt-Epic-1.21.1/mods"
```

Для профиля с обоими дополнительными генераторами:

```sh
python3 scripts/fetch-official-mods.py --mods-dir "/полный/путь/Bekhilitt-Epic-1.21.1/mods" --include-worldgen
```

На Windows используйте `py -3` вместо `python3` и свой путь в кавычках. На всех
системах сначала проверьте `python3 --version` или `py -3 --version`.

Загрузчик читает manifest рядом с папкой `scripts`, использует только HTTPS и
ограниченный список официальных хостов, проверяет каждый redirect, размер и
SHA-256. Данные сначала пишутся во временный `.part`; окончательное имя появляется
лишь после успешной проверки. Существующий корректный файл повторно не скачивается.
Существующий некорректный файл **не перезаписывается**: остановитесь и самостоятельно
уберите именно этот файл из `mods`, затем повторите установку. Пароли, API-ключи,
логин, запуск игры, принятие EULA и распаковка модов загрузчику не нужны.

Если CurseForge/Modrinth возвращает ошибку, HTML или блокировку, автоматический
шаг завершится ошибкой и напечатает официальную страницу. Не обходите блокировку
зеркалами. Откройте указанную страницу в обычном браузере, скачайте закреплённый
JAR вручную в `mods` с **точным именем из manifest**. Затем проверьте всё офлайн:

```sh
python3 scripts/fetch-official-mods.py --mods-dir "/полный/путь/Bekhilitt-Epic-1.21.1/mods" --include-worldgen --verify-only
```

Без worldgen уберите `--include-worldgen`. Код завершения 0 означает совпадение
**всех выбранных зависимостей** с manifest; любой другой код означает неполную
установку. Не запускайте такой профиль до исправления. Hash-проверка не заменяет
доверие к исходному пакету/manifest и не подтверждает runtime-совместимость.
Посторонние JAR загрузчик не удаляет, не проверяет и не разрешает автоматически.

Ограничения: сеть может блокировать официальный download endpoint; гарантирован
безопасный отказ, а не обход защиты. Запись готового файла использует атомарный
hard link без перезаписи: на файловой системе без hard-link поддержки используйте
ручную загрузку и `--verify-only`. Не запускайте параллельно несколько установщиков
в одну папку. Helper проверен локальными fake-fixture тестами; это не самостоятельное
подтверждение доступности внешних хостов на вашем компьютере.

## 3. Первый вход и настоящее управление Epic Fight

1. Запустите именно новый профиль. В списке модов проверьте Minecraft/NeoForge,
   Bekhilitt и Epic Fight. Для расширенного профиля также Terralith и Explorify.
2. Создайте новый одноразовый мир с именем `Bekhilitt-Test` или
   `Bekhilitt-Test-Epic`. Включите команды для тестового эпизода, выберите
   сложность **не Peaceful**. Ценные миры для этого эпизода не подходят.
   Для первого знакомства с Terralith 2.5.8 + Explorify 1.6.5 рекомендуем
   во вкладке «Мир» задать проверенный ключ генератора **`-8871378200959666735`**.
   Этот seed пройден с нуля до END, в том числе на финальном JAR.
3. Освободите выбранную ячейку хотбара, вторую руку и все слоты брони. Эпизод
   выдаёт временный учебный двуручный меч; ваши предметы подменяться не должны.
4. Выполните `/bekhilitt start disposable`. Для состояния используйте
   `/bekhilitt status`, для штатной остановки `/bekhilitt stop`, для продолжения
   контрольной точки `/bekhilitt resume`. Это первый эпизод с фиксированным
   каноническим исходом, а не свободная новая кампания.

Стартовый лагерь пока привязан к области около X/Z 0/0. На слишком крутом
случайном рельефе фундамент может превысить безопасный лимит. Тогда появится
сообщение `Combined camp block budget exceeded`: авторские блоки не размещаются,
игрок возвращается и контрольная точка сохраняется. Создайте **новый** одноразовый
мир с рекомендованным seed; не повышайте лимиты и не удаляйте защитные записи.
Автоматического поиска другой долины в этой версии нет.

Атаку, guard, dodge, анимацию и боевой режим исполняет **сам Epic Fight**.
Стандартные назначения: **короткие нажатия ЛКМ — атаки/комбо, ПКМ удерживать
для защиты, Left Alt (Alt слева) — перекат**, R — смена боевого режима.
Не удерживайте ЛКМ для обычной атаки: у Epic Fight общая привязка
ATTACK/WEAPON_INNATE, и удержание пытается запустить innate skill, запрещённый
в этом уроке. Истина для вашего профиля — реальные назначения в
**Настройки → Управление → Назначение клавиш**, раздел Epic Fight, и подсказки HUD.
Если вы переназначили клавиши, пользуйтесь назначенными; старое управление
Fabric-прототипа сюда не переносится. Проверьте конфликты клавиш в этом меню.
F5 меняет вид камеры в свободном бою; сюжетная камера может временно менять вид.
Мод не должен глобально переписывать ваши настройки Epic Fight.

При ошибке зависимости/сохранения не удаляйте campaign-файлы ради обхода ошибки.
Закройте мир и сохраните его копию и `logs/latest.log` для диагностики. Резервную
копию восстанавливайте при полностью закрытой игре. Старый профиль для этого
не нужен и не изменяется.

### Необязательная практика после END

После завершения первого эпизода его владелец может выполнить
`/bekhilitt practice` **в том же одноразовом одиночном мире** `Bekhilitt-Test*`.
Это отдельная демонстрация нативных Demolition Leap и Meteor Slam до пяти минут,
без урона, наград, повторного боя с Гриффитом или нового сюжетного прогресса.
На dedicated server практика недоступна. Нужны пустая выбранная ячейка хотбара,
пустая вторая рука и броня, а также пустые слоты навыков MOVER/IDENTITY;
существующие навыки не заменяются.

- **Demolition Leap:** стоя на земле, посмотрите вверх, удерживайте Space
  примерно **0,6–2 секунды** и отпустите. При переназначении используйте свою
  клавишу Epic Fight Mover Skill.
- **Meteor Slam:** находясь более чем в **шести блоках над землёй**, посмотрите
  вниз минимум на **40°** и **коротко нажмите ЛКМ** (свою клавишу Attack).
  Это перехват обычной атаки самим навыком, а не отдельная кнопка Identity.
  Удержание ЛКМ для этого не подходит.
- **Возврат:** `/bekhilitt stop`. Упражнение также завершается по лимиту времени
  или при выходе за разрешённую область. Навыки выдаются временно, а не открываются
  навсегда. Практика возвращает исходные положение/режим, снаряжение и состояние
  временно выданных навыков.

Нативное выполнение обоих приёмов проверено в runtime; это не утверждение о
полном прохождении всей recovery-матрицы. На время практики мод сохраняет исходное
правило `mobGriefing`, устанавливает `false` для защиты блоков, затем восстанавливает
именно прежнее значение. Не меняйте это правило и временное снаряжение во время
упражнения. Входящий и исходящий урон закрыты: это демонстрация движений и эффектов.

Если lease, snapshot или другие данные возврата повреждены либо имеют неизвестный
будущий формат, восстановление **безопасно блокируется**, защитные отметки остаются.
Не удаляйте markers, lease, snapshot или NBT-поля и не угадывайте исходные координаты,
режим или правило. `/bekhilitt stop` не исправляет повреждённые данные. Закройте
клиент, сохраните отдельную копию проблемного мира и следуйте разделу
[«Если восстановление заблокировано»](NATIVE_SKILL_PRACTICE.md#если-восстановление-заблокировано):
для восстановления нужна согласованная резервная копия этого же мира. Без неё
сохраните мир для диагностики и используйте новый одноразовый мир.

## 4. Отдельный локальный серверный комплект

Это инструкция подготовки **новой локальной папки**, не развёртывание VPS,
не публичный сервер и не готовый к игре dedicated-профиль. Кооператив не заявлен.
Dedicated world boot в текущей проверке не выполнен: установщик/обнаружение модов и запуск мира
являются разными проверками. Серверный EULA остаётся **`eula=false`**, пока
пользователь сам не ознакомится с условиями и не решит принять их.

1. Создайте пустую папку `Bekhilitt-Epic-LocalServer`, отдельно от клиентского
   профиля, старого сервера и любых сохранений. Используйте Java 21.
2. Скачайте официальный установщик NeoForge **21.1.219**
   ([инструкция сервера NeoForge](https://docs.neoforged.net/user/docs/server/)), выберите Install server
   и эту папку; либо из этой папки выполните для скачанного установщика:

   ```sh
   java -jar neoforge-21.1.219-installer.jar --installServer
   ```

3. Положите собственный Bekhilitt JAR в серверный `mods`; получите те же официальные
   зависимости helper-командой с серверным `--mods-dir`. Epic Fight нужен на обеих
   сторонах. Worldgen-моды нужны на стороне создаваемого мира; для воспроизводимого
   экспериментального профиля держите одинаковый закреплённый набор на клиенте
   и сервере, без разных версий одного мода.
4. В сгенерированном `user_jvm_args.txt` добавьте отдельными строками
   `-Dbekhilitt.dev=true` и `-Dbekhilitt.dedicatedTest=true`. Второй флаг явно
   разрешает только тестовый dedicated-сценарий. Не удаляйте остальные параметры.
5. В новом `eula.txt` оставьте `eula=false`. Изучите
   [Minecraft EULA](https://www.minecraft.net/en-us/eula). Установочный комплект
   и helper не принимают её за вас. Только после личного согласия пользователь
   может сам поменять значение на `true`; иначе подготовка заканчивается здесь.
6. После принятия условий пользователем подготовьте отдельный новый мир:
   `level-name=Bekhilitt-Test-Server`, `difficulty=normal`, `max-players=1`,
   `server-ip=127.0.0.1`, `online-mode=true` в `server.properties`.
   Привязка к localhost предназначена для клиента на том же компьютере. Не
   открывайте порт в роутере/фаерволе; VPS, внешний доступ и offline-mode не нужны.
7. Запускайте штатный сгенерированный `run.sh nogui` (Linux/macOS) или
   `run.bat nogui` (Windows). Клиент с новым профилем подключается к
   `127.0.0.1:25565` при стандартном порте. Команды эпизода требуют соответствующих
   прав оператора в этом личном тестовом сервере; предоставляйте их только своему
   проверенному игровому аккаунту. Второго игрока этот эпизод не поддерживает.
8. Завершайте сервер командой `stop` в его консоли; перед копированием мира
   дождитесь штатного окончания процесса. Не переносите сюда сохранения 1.21.11.

Если сервер отказывает из-за EULA, это ожидаемый барьер до вашего согласия.
Если после согласия он не запускается, сохраните его `logs/latest.log`; не
отключайте проверку аккаунта, не меняйте версии на случайные и не удаляйте мир.
