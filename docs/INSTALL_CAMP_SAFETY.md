# Запуск исправленного кандидата 1.2.0-epic.4

Используйте отдельный профиль Minecraft 1.21.1 + NeoForge 21.1.219, Java 21 и JVM-флаг `-Dbekhilitt.dev=true`. Официальные зависимости и их проверка описаны в INSTALL_EPIC_PROFILE.md и DEPENDENCIES.json.

При закрытой игре сохраните копию тестового профиля/мира. В его mods оставьте только один собственный Bekhilitt JAR: `bekhilitt-1.2.0-epic.4.jar`. Не кладите epic.1, epic.2, epic.3 и epic.4 одновременно. Комплект переносимый; машинно-зависимый Mac launcher в него не входит.

Для нового прохождения создайте обычный одноразовый мир `Bekhilitt-Test-Camp4`, команды включены, Normal, seed `-8871378200959666735`. Запуск `/bekhilitt start disposable`. Не используйте обычные сохранения.

После END выберите «Остаться в лагере». `/bekhilitt camp` возвращает в завершённый лагерь; рядом с Каской/Гриффитом ПКМ или `/bekhilitt talk` открывает повторный разговор. `/bekhilitt stop` возвращает исходное состояние. `/bekhilitt resume` продолжает эпизод, а после END открывает лагерь. `/bekhilitt practice` запускает отдельную прежнюю практику, безопасно покидая лагерь. `/bekhilitt status` показывает состояние.

Стрелки/кнопки Назад и Далее листают длинный текст; отпускайте клавишу между нажатиями. Esc в обязательном сюжетном диалоге отменяет эпизод с возвратом; в END и повторном разговоре только закрывает карточку.

Бой: короткие ЛКМ, защита удержанием ПКМ, перекат левый Alt/Option, R режим боя, F5 камера. В практике Leap: смотреть вверх, удерживать Space и отпустить. Slam: выше шести блоков смотреть вниз минимум на 40° и коротко нажать ЛКМ.

После сбоя не удаляйте snapshot/NBT markers. Сохраните закрытый мир и лог для диагностики. Границы фактической проверки перечислены в QA_CAMP_SAFETY.md.

Лагерь — безопасная небоевая зона для прогулки и разговоров. Для нативных прыжков используйте practice, для обычной игры сначала `/bekhilitt stop`. Безопасность активна только пока идёт посещение; она не означает глобальную неуязвимость после выхода.
