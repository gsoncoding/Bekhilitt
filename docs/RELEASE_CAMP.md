# Изменения 1.2.0-epic.2

Новая экспериментальная итерация двух одобренных изменений: компактный диалог и свободный лагерь после дуэли.

Нижняя полупрозрачная панель освобождает верхнюю половину экрана, сохраняет штатный размер шрифта, переносит длинный текст на страницы с возвратом назад и счётчиком. Удержание кнопки не пропускает несколько страниц. Финальная карточка ожидает чтения и больше не возвращает игрока автоматически по таймеру.

После END доступна прогулка, повторное обращение к обоим NPC, безопасный выход и команда camp для следующего посещения. Обязательная дуэль не повторяется, эффекты вступления не выдаются снова. Практика сохранена как отдельный режим с одним исходным адресом возврата. Новая миссия или сюжетное решение не добавлены.

Записи кампании не меняют формат. Посещение добавляет собственную строгую запись параметров игрока, которая сохраняется до разрешённого движения и удерживает защиту при неудачном восстановлении. Старые профили не обновлялись на месте.

Сборка и автоматические проверки пройдены. Полная игровая приёмка новой логики пока не подтверждена из-за недоступного управления Java-окном на Mac. См. [QA](QA_CAMP.md), [запуск](INSTALL_CAMP.md), [решение](decisions/010-compact-dialogue-free-camp.md). Предыдущие QA-документы относятся к epic.1 и не являются доказательством прохождения epic.2.
