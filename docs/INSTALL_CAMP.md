# Запуск 1.2.0-epic.2 — компактные диалоги и свободный лагерь

На подготовленном Mac рядом с папкой source находится **Запустить Bekhilitt Epic 2.command**. Двойной щелчок запускает только новый mac-profile. Если этот клиент уже открыт, второй экземпляр не нужен. Версию 1.2.0-epic.1 и её миры оставьте отдельно.

Стек сохранён: Minecraft 1.21.1, NeoForge 21.1.219, Epic Fight 21.17.3.1, Terralith 2.5.8, Explorify 1.6.5, Java 21. Перенос старых миров не выполнялся. На другом компьютере используйте базовую [инструкцию отдельного профиля](INSTALL_EPIC_PROFILE.md), JAR именно epic.2 и JVM-флаг `-Dbekhilitt.dev=true`. Зависимости получают штатным scripts/fetch-official-mods.py; внешний комплект их не перепаковывает.

Создайте **новый** одноразовый мир **Bekhilitt-Test-Camp2**: обычный тип, не суперплоский; сложность Normal; команды включены. Seed **-8871378200959666735** перенесён из предыдущего проверенного профиля с теми же версиями генераторов. Повторное прохождение этого seed в epic.2 пока не подтверждено.

Освободите выбранную ячейку хотбара, вторую руку и броню перед первым эпизодом. Начало: `/bekhilitt start disposable`.

Диалог: кнопки Назад/Далее, стрелки влево/вправо, Tab для выбора кнопки, Enter или Space для её активации. Нажатие нужно отпускать между страницами. Текст не отправляет сюжетный ответ, пока не прочитана последняя локальная страница. В текущей фиксированной истории нет ветвящихся ответов.

После вступления нажмите **Остаться в лагере** или Esc. В финальной карточке и повторном разговоре Esc закрывает карточку; в обязательном сюжетном диалоге Esc по-прежнему приостанавливает эпизод и возвращает игрока.

В лагере можно ходить и смотреть по сторонам. Подойдите к Каске или Гриффиту не дальше четырёх блоков и нажмите ПКМ. Альтернатива — `/bekhilitt talk` у персонажа. Карточки повторяемые, без наград, новой миссии и повторного боя.

- `/bekhilitt stop` — выйти и восстановить исходное состояние.
- `/bekhilitt camp` — вернуться после END, stop или перезахода.
- `/bekhilitt resume` — продолжить незавершённый эпизод; после END войти в лагерь.
- `/bekhilitt practice` — существующая отдельная практика. Из лагеря сначала выполняется безопасный выход, затем практика. После её окончания возвращайтесь через camp.
- `/bekhilitt status` — состояние кампании, которое остаётся COMPLETE при прогулках.

Бой: короткие ЛКМ — атаки, удержание ПКМ — защита, левый Alt/Option — перекат, R — боевой режим, F5 — камера. Практика после END: смотреть вверх, удерживать Space 0,6–2 секунды и отпустить для Leap; выше шести блоков смотреть вниз минимум на 40° и коротко нажать ЛКМ для Slam.

После reload/crash происходит восстановление исходного положения и состояния; возвращаться в лагерь следует командой camp. Если восстановление отказано, не удаляйте snapshot/NBT markers: сохраните копию мира при закрытом клиенте и лог для диагностики. Неизвестные данные не сбрасываются автоматически.
