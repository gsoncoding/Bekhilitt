# QA кандидата 1.2.0-epic.4

13 октября 2026. JAR SHA-256 `8cee092be3a4bf191991a5bb4b201ecd52e80f66e6bfb3d8e387be5f1087a08a`.

## Автоматические проверки

- Java 21, offline clean build: все 8 задач выполнены, 209 JUnit, 0 failures/errors/skipped.
- 56 Python tests прошли.
- 18 новых safety regressions: bounded active visit/level/readiness, границы региона/фундамента, деактивация после stop, native item/XP event contracts и target event semantics. Эти тесты не заменяют наблюдение реального mob AI.
- Исправление CANCEL из epic.3 сохранено: 12 регрессий; mutation старого порядка ломал 5 тестов.

## Реальная игра

- Точный final JAR запущен в отдельном production-профиле Minecraft 1.21.1 / NeoForge 21.1.219 / Epic Fight 21.17.3.1. Проверки проводились только на новой копии завершённого тестового мира.
- Вход в camp из Survival, читаемая подсказка «Безопасный лагерь · Бой отключён», повторный разговор с Каской и выход через Esc работают.
- Созданный рядом QA Husk не преследовал посетителя и ушёл бродить; его координаты изменились на удалённые от игрока, без удаления/NoAI. Обычные ночные мобы не собирались вокруг игрока как раньше.
- QA diamond у ног оставался ItemEntity с count=1, Inventory игрока оставался []. После stop durable Inventory также пуст.
- Принудительно зажжённый vanilla QA Creeper завершил взрыв; диалог/NPC остались доступны, здоровья не убавилось. Сравнение 3136 block names вокруг палатки до и после durable stop: 0 изменений. Состояния блоков/весь мир этим сравнением не покрыты.
- stop вернул точные исходные координаты [72.5,66,-68.5] и Survival, health/food 20, NeoForgeData {}, без camp marker.
- За пределами лагеря обычный QA Husk реально наносил урон и убил одноразового QA-персонажа. После respawn отдельная пассивная тестовая цель потеряла Health 20.0 → 19.06 от реального короткого ЛКМ. Это проверка отсутствия глобальной блокировки урона, не прохождение сюжетного боя.
- Save-and-quit прямо из camp → rejoin восстановили захваченную перед посещением позицию и Creative, marker отсутствует, returnPending=false. После предыдущей отдельной проверки Survival режим был намеренно сменён на Creative для безопасного измерения исходящего урона. Завершённый campaign snapshot остался byte-identical baseline.

## Границы

- Intentional crash не выполнялся: отдельного разрешения на принудительное завершение тестового мира нет. Обычный stop/save/reload проверяется отдельно.
- Полное повторное прохождение нового эпизода, все размеры окна/масштабы, произвольные модпаки/миры и dedicated server не заявляются проверенными.
- Мобы остаются в мире и могут бесцельно бродить рядом. Защита не удаляет существующих существ, не устанавливает NoAI и не меняет глобальные gamerules.
- Документы QA_CAMP/QA_CAMP_FIX описывают прежние версии. Выданные архивы неизменны.
