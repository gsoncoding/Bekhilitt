# Кандидаты в боссы из сериала 1997 года

Содержит сюжетные сведения. Требование апостолов-боссов утверждено; конкретный набор игровых встреч ещё не утверждён. Проверка 12 октября 2026 года ограничена справочниками и доступными описаниями, без просмотра кадров. Таблица не является исчерпывающим каталогом всех фоновых существ.

Полные страницы Fandom о сериях при открытии были недоступны; поисковые выдержки использованы только как предварительные указатели. Не считать их равными прямой сверке. Для Зодда и барона подтверждён только указанный объём фактов. Формы, скорости, сопротивления и точные атаки нельзя достраивать из памяти. Персонажи иных адаптаций не включены автоматически; представители иной сверхъестественной категории не объявляются апостолами по внешнему сходству.

## Условие допуска в разработку

Для каждой встречи нужны bossId, characterId, sourceEdition, episodeRefs, подтверждение присутствия Гатса, формы с отдельными свидетельствами, набор атак, состояние до/после, канонический исход, место арены и проверка хронологии. Статусы: `candidate`, `synopsis_checked`, `directly_verified`, `design_ready`. Сейчас ни одна встреча не имеет design_ready.

Первый кандидат для будущего технического теста — Зодд, как предложение. Его не помещать рядом с первой встречей Соколов: техническая арена testOnly не продвигает основную кампанию. До поздних глав требуется поэпизодный просмотр и индивидуальный учёт фоновых апостолов. Варианты отдельных режимов для конфликтов охвата не являются утверждёнными задачами.
