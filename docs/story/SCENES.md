# Реестр сцен начала кампании

Все сцены **предложены**, игровые определения и постановка ещё не созданы. ID сохраняются при переименовании заголовка. Эпизодные привязки начала сверены по справочникам в [CHRONOLOGY](CHRONOLOGY.md); постановка и реплики требуют прямой сверки.

| ID | Драматическая и игровая задача | Вход → результат | Этап |
|---|---|---|---|
| `bekhilitt:golden_age/meeting` | Дать игроку встретить отряд и обратить внимание на Гриффита | Вход в тестовую область → доступен разговор о поединке | P5 |
| `bekhilitt:golden_age/first_duel` | Показать противостояние и компетентность Гриффита через участие игрока | Разговор завершён → подтверждён исход канонического поединка вступления | P5 |
| `bekhilitt:golden_age/camp_intro` | Дать почувствовать переход к жизни отряда | Флаг поединка → открыто знакомство с лагерем | P5 |
| `bekhilitt:golden_age/first_sortie` | Проверить совместное действие и последствия | Знакомство с лагерем → возвращение после задания | P5, эпизод не выбран |

Связанные будущие задания: `bekhilitt:first_duel` (available → active → completed), `bekhilitt:camp_intro` (locked → available → active → completed). Это проект этапов, а не уже существующие JSON. Первый поединок использует флаг `bekhilitt:first_duel_done`. Открытие следующего задания и фиксация исхода выполняются одним переходом кампании.

Слоты реплик: `griffith_meeting_01`, `griffith_duel_01`, `griffith_camp_01`. Слоты указывают предполагаемого говорящего постановки, но **не подтверждают атрибуцию какого-либо текста**. Их точный текст пуст, статус — ожидает выбора фрагмента и сверки в [SOURCES](SOURCES.md).

Прерывания и повтор не описываются отдельными правилами для каждой сцены: применяются [общие правила](../STORY_DATA.md), а конкретный recoveryNode выбирается при создании игровых данных. У `first_duel` восстановление предлагается перед началом попытки поединка; у разговора — перед безопасным входным узлом.

## Отдельный учебный эпизод

Утверждённый первый результат описан в [конституции](../CONSTITUTION.md): короткий разговор/встреча с Гриффитом → тренировочный поединок с одним бойцом отряда, не Гриффитом. Личность бойца, цель и допустимый исход ещё открыты. Это отдельный testOnly-маршрут P2–P4; таблица выше сохраняет проектные ID **основной кампании**, их постановка перенесена в последующий канонический срез P5.

`first_duel`, его задания, флаг и слоты реплик не переименовываются в тренировку. Для учебного эпизода отдельные ID и слоты пока не заведены; дополнительные реплики и механики не утверждены.

## Связь с обязательной хронологией

`meeting` покрывает encounter_hawks; перед `first_duel` обязательны initial_clash и recovery_and_challenge из реестра хронологии. Для них нужны отдельные узлы или сцены; пропускать их в финальной кампании нельзя. `first_duel` завершает joining_duel_resolved, канонический исход — поражение Гатса. Победа в отладочном стенде не открывает каноническое задание. `camp_intro` не переносит поздние откровения серии 4 перед рейдом серии 3. `first_sortie` остаётся предложением и должно пройти проверку порядка.

Линия Гриффита связывает эти сцены через память участника и текущую цель, см. [GRIFFITH](GRIFFITH.md). meeting показывает занятого командира; first_duel фиксирует совместный факт; camp_intro использует уже обновлённый контекст. first_sortie позднее даёт отдельный факт результата через наблюдение или доклад. Повтор сцены не повторяет изменение отношений.
