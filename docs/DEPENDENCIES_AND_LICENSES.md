# Зависимости, происхождение ресурсов и лицензии

Проверено 13 октября 2026 года. Этот документ описывает состав исходников и
экспериментального комплекта; он не меняет лицензии сторонних проектов и не
объявляет публичную публикацию разрешённой.

## Собственный проект

Метаданные Bekhilitt сохраняют `All Rights Reserved`. Отдельная открытая лицензия
на собственный код и графику пока не выбрана. Наличие исходников само по себе не
меняет эти условия. Товарные знаки, персонажи и первоисточник «Берсерк» не объявляются
собственностью проекта; официальное одобрение правообладателей не заявляется.
Реплики первого эпизода являются собственным пересказом. Записи озвучки, кадры
аниме, музыка и точные непроверенные цитаты не включены.

Собственные ресурсы находятся в `src/main/resources/assets/bekhilitt`:

- `textures/entity/casca.png` создаётся `scripts/generate-casca-texture.py`;
- `animmodels/entity/griffith.json` и `textures/entity/griffith.png` создаются
  `scripts/generate-griffith-assets.py`;
- `animmodels/entity/guts.json` и `textures/entity/guts.png` создаются
  `scripts/generate-guts-assets.py`;
- локализации и данные эпизода написаны для проекта.

Три генератора строят геометрию и пиксели программно и не читают внешние картинки.
Изолированная повторная генерация пяти перечисленных файлов дала точное совпадение
байтов с исходным деревом. Индексы суставов используются как контракт API зависимости;
готовые модели, анимации и текстуры Epic Fight не копируются.

## Единственный вложенный сторонний бинарный файл

`gradle/wrapper/gradle-wrapper.jar` — неизменённый официальный Gradle Wrapper 9.2.1,
инструмент сборки под Apache-2.0. SHA-256:
`423cb469ccc0ecc31f0e4e1c309976198ccb734cdcbb7029d4bda0f18f57e8d9`.

Полный текст из его `META-INF/LICENSE` сохранён в
[licenses/gradle-wrapper-LICENSE.txt](licenses/gradle-wrapper-LICENSE.txt).
Исходные заголовки copyright/Apache-2.0 в `gradlew` и `gradlew.bat` сохранены.
В самом проверенном wrapper JAR отдельного NOTICE нет. Полная Gradle distribution
не вложена: wrapper получает её отдельно. Её закреплённый SHA-256:
`72f44c9f8ebcb1af43838f45ee5c4aa9c5444898b3468ab3f4af7b6076c5bc3f`.

Источники: [официальные SHA-256 Gradle](https://gradle.org/release-checksums/),
[лицензии Gradle 9.2.1](https://github.com/gradle/gradle/blob/v9.2.1/LICENSE).
Apache-2.0 wrapper не является лицензией собственного кода Bekhilitt.

## Игровые зависимости устанавливаются отдельно

Точные имена файлов, SHA-256, размеры и официальные страницы зафиксированы в
[`DEPENDENCIES.json`](../DEPENDENCIES.json). Проверку выполняет
`scripts/fetch-official-mods.py`; подробности находятся в
[инструкции профиля](INSTALL_EPIC_PROFILE.md).

- Minecraft 1.21.1 и NeoForge 21.1.219 нужны для текущего экспериментального
  runtime; Java/JDK 21 — для запуска/сборки. Они не вложены.
- Epic Fight 21.17.3.1 обязателен. Его JAR объявляет `Code: GPL-3.0; Assets: All
  Rights Reserved`. [Официальная политика проекта](https://github.com/Antikythera-Studios/epicfight/blob/1.21.1/README.md#license)
  допускает собственный код, использующий Epic Fight как зависимость, и запрещает
  перераспространение его assets. Bekhilitt использует внешнюю зависимость;
  Epic Fight JAR, source JAR и assets не включены в дерево или архив.
  [Закреплённый официальный выпуск](https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod/files/8175609).
- Terralith 2.5.8 и Explorify 1.6.5 относятся только к экспериментальному
  worldgen-профилю. Для компиляции Bekhilitt не нужны. Они не вложены и
  устанавливаются отдельно с официальных страниц из manifest. Их материалы
  не получают лицензию Bekhilitt.
- Gradle plugin, NeoForge toolchain и JUnit получаются по build-конфигурации;
  эти библиотеки не копируются в репозиторий или собственный runtime JAR.
  Pillow нужен только для изменения/повторного создания собственной графики,
  не для обычной Java-сборки; сам пакет Pillow не включён.

Этот перечень не означает, что чужие лицензии заменены одной общей лицензией
проекта. Добавление новой вложенной зависимости или чужого ресурса требует
отдельной проверки происхождения и условий до упаковки.

## Границы дерева и архива

В Git-дерево и source ZIP не входят `libs`, `run`, миры, NBT snapshots,
`build`, кэши, логи, личные пути, токены, сторонние JAR и внутренние QA-артефакты.
Исторический Mac launcher не переносится. Публичные QA-документы содержат
результаты и ограничения, а не игровые сохранения или машинные отчёты.

Пользовательский release ZIP отличается от Git-дерева: в него отдельно входит
собственный проверенный runtime JAR и, при явном выборе, игровые PNG. Подробности
и проверка состава: [PACKAGING_EPIC_RELEASE](PACKAGING_EPIC_RELEASE.md).
История прежнего Fabric-прототипа 1.0.0 сохраняется в Git; это не активный
runtime текущей NeoForge-версии.
