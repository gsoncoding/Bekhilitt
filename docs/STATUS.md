# Текущее состояние Bekhilitt

12 октября 2026 года. **1.0.0 — локальный технический боевой прототип**, не готовый полный эпизод. Ветка `codex/bekhilitt-combat-prototype` в отдельной копии от `ee930f0a2f24411aae5c988ed2b80c2e642bbf68`. Прежний checkout task-5 не изменён. Публикация не разрешена и не выполнялась.

## Реализовано

Fabric-проект с закреплёнными Minecraft 1.21.11, Loader 0.19.5, Fabric API 0.141.6+1.21.11, Loom 1.14.10, Gradle 9.2.1 и Java 21. Чистые серверные правила дуэли, одноразовая площадка, игрок в роли Гатса, временная модель Гриффита, удар/защита/уклонение, цикл противника и ограниченный переход к постановочному поражению. Конец сообщает о каноническом вступлении, но не записывает кампанию. Отмена и штатный выход очищают попытку. Клиент отвечает за ввод, сервер — за результат.

Полный эпизод с ранением, Каской и разговорами остаётся следующим сюжетным объёмом. Клавиши, числа и завершающий приём — заменяемые defaults, не утверждённый дизайн. Подробности: [COMBAT_PROTOTYPE](COMBAT_PROTOTYPE.md), [ADR 006](decisions/006-combat-prototype.md), [CHANGELOG](../CHANGELOG.md).

## Пройдено

- Gradle build: BUILD SUCCESSFUL; компиляция общего и клиентского кода, remapJar, версия 1.0.0 в JAR.
- JUnit после исправления мыши: **21 тест, 0 ошибок, 0 провалов, 0 пропусков** (12 боя, 9 ввода). Проверяются в том числе короткие клики, удержание/отпускание, меню/фокус, вход/выход/отключение, отсутствие повторов и немедленное снятие защиты.
- Переносимая Java 21.0.12.1 из официального Adoptium в соседней `.tools`; системная Java не заменена. Wrapper проверяет официальный SHA-256 Gradle distribution.
- Настоящий dev-клиент запущен: Minecraft/Fabric загрузились, графические атласы и звук инициализированы. Это подтверждение запуска клиента, **не проверка боя в мире**.
- Пользователь проверил исходную сборку: новый мир, `/bekhilitt start`, модель Гриффита, попадания и конечное сообщение. Журнал фиксирует старт в 21:43:20, три попадания в 21:43:35–38 и исход в 21:43:44. Отзыв: действия и финал непонятны. Это пользовательская проверка исходной сборки, не самостоятельный QA исправленной.
- По коду выявлены и исправлены: отсутствие отправки взмаха самому игроку (`swing(hand, true)`), перекрытие HUD предупреждением противника, ранний финал от простого ввода. Теперь нужны результаты действий и минимум 20 секунд; предупреждение 3 секунды, результат 5 секунд. Версия осталась 1.0.0.
- По запросу пользователя управление изменено на ЛКМ/ПКМ/R. WASD и камера мышью ванильные. Клиентский mixin отменяет ванильные attack/continueAttack/useItem только в дуэли и до отпускания кнопки после выхода. Три точки инъекции сверены с bytecode Minecraft и remapped JAR; фактическое применение mixin в новом игровом запуске пока не проверено. Старые точные mod defaults J/K/L мигрируют при следующем запуске, остальные mod bindings и ванильные привязки сохраняются.
- JSON ресурсов корректен, локальные ссылки документации проверены, `git diff --check` без ошибок.

## Не пройдено / блокеры

- Полный запуск выделенного сервера: мод распознан Loader, затем Minecraft остановился на EULA. Согласие автоматически не записывалось. Gradle exit 0 здесь не означает готовый игровой сервер.
- Самостоятельный игровой QA исправления: пользователь разрешил тестирование, но поддерживаемые попытки CUA по имени Java/Minecraft, пути процесса и фактическому bundle ID JDK вернули `Invalid app`. Другие технологии ввода не использовались. Работающий клиент не перезапускался и содержит исходный код до исправлений. Обновлённый JAR требует следующего запуска после сохранения пользователем текущей сессии.
- Запрошенный OptiFine: в dev-профиле отсутствует; проверка совместимости зафиксирована в инструкции стенда. Без подтверждённой связки с Fabric не добавляется.

## Не запускалось

Игровые сценарии контакта/блока/уклонения и постановки, переназначение в UI, пауза/фокус, прерывание и повторный вход, восстановление после аварии, FPS/профилирование, совместимость с другими модами. P0/P0C пройдены частично, P1–P4 не объявлены завершёнными.

## Артефакт и запуск

`build/libs/bekhilitt-1.0.0.jar`; рядом sources JAR. SHA-256: `verification/artifact.sha256`; тесты: `verification/unit-tests.xml`, `verification/input-tests.xml` и `build/reports/tests/test/index.html`. Локальные журналы: `verification/client-launch.log`, `verification/server-launch.log`, `verification/mouse-input-build.log` (не входят в Git).

Для Linux подготовлен `dist/bekhilitt-1.0.0-test-profile.zip`: мод, Fabric API, инструкции и контрольные суммы. [Инструкция Linux](LINUX_TESTING.md) указывает Minecraft 1.21.11 / Loader 0.19.5 / API 0.141.6+1.21.11 / Java 21 и обязательный JVM-флаг `-Dbekhilitt.dev=true`. Проверено отсутствие собственных native-библиотек в JAR; Linux не подключался и не запускался.

На этом Mac: `Play-Bekhilitt.command` либо `./scripts/dev.sh`. Не запускать второй клиент, если первый открыт. Создать новый одноразовый мир с командами → `/bekhilitt start`; отмена — `/bekhilitt stop`. Каталог игры только `run/client`. Установка в обычный Minecraft не выполнялась. Предупреждение о замене блоков и ручной чеклист — в инструкции стенда.

Далее пользователь пробует 1.0.0 и решает, что убрать или добавить. Мелкие исправления группируются внутри этапа; следующая пользовательская версия означает содержательное обновление опыта. PR, релиз и тег не создавались.
