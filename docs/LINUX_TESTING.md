# Проверка Bekhilitt 1.0.0 на Linux / Omarchy

Мод переносим на уровне артефакта: Java bytecode для Java 21, без собственных `.dylib`, `.so`, JNI или вызовов macOS. Minecraft/LWJGL и Java для конкретной архитектуры ставит выбранный launcher. **Фактический запуск на Linux/Omarchy ещё не проводился**, совместимость графических драйверов и Wayland/XWayland не подтверждена.

## Точный состав тестового профиля

| Компонент | Версия / файл |
|---|---|
| Minecraft Java Edition | **1.21.11** |
| Fabric Loader | **0.19.5** |
| Java runtime | **21**, соответствующая архитектуре Linux; сборка на Mac проверена с Temurin **21.0.12.1** |
| Bekhilitt | `bekhilitt-1.0.0.jar` из `build/libs/` (не sources JAR) |
| Fabric API | `fabric-api-0.141.6+1.21.11.jar` |

В `mods/` нужны только последние два JAR. Fabric Loader устанавливается в профиль launcher, его installer не кладётся в `mods`. Gradle, JDK для разработки и исходники для готового JAR не нужны. macOS JDK из соседней `.tools` переносить на Linux нельзя. OptiFine, OptiFabric, Sodium и Iris не включены.

## Установка пользователем

1. В своём launcher создать **отдельный профиль/instance** с отдельной игровой папкой, например `~/Games/Bekhilitt-test-1.0.0`. Не использовать обычный профиль и не переносить существующие миры.
2. Выбрать Minecraft **1.21.11**, Fabric Loader **0.19.5**, Linux Java **21**. Для ручной установки использовать [официальную инструкцию Fabric для Linux](https://docs.fabricmc.net/1.21.11/players/installing-fabric/linux).
3. Скопировать оба runtime JAR в `mods/` этого профиля. Удалять или менять файлы других профилей не требуется.
4. В **JVM arguments только этого тестового профиля** добавить `-Dbekhilitt.dev=true`. Это обязательный переключатель тестового стенда; без него `/bekhilitt start` отклоняется. Это не аргумент самой игровой команды.
5. Запустить, создать новый одноразовый одиночный мир с разрешёнными командами. Выполнить `/bekhilitt start`.
6. ЛКМ — удар, ПКМ удерживать — защита, R — уклонение, WASD — движение, мышь — камера, F5 — вид от третьего лица. Выход из попытки: `/bekhilitt stop`.

Команда заменяет блоки X/Z −10…10, Y 100…105. Профиль предназначен только для одноразовых миров. Не открывать LAN для этой версии.

Локальный архив `dist/bekhilitt-1.0.0-test-profile.zip` содержит `mods/`, эту инструкцию и SHA256SUMS. Он не содержит игру, Java, Loader или пользовательские настройки. Его можно перенести самостоятельно; удалённое подключение и установка на Linux не выполнялись.

## Что проверить после запуска

Использовать полный чеклист [COMBAT_PROTOTYPE](COMBAT_PROTOTYPE.md). Вначале проверить обычные ЛКМ/ПКМ вне дуэли, затем отсутствие двойного ванильного действия в дуэли, короткие клики, защиту с отпусканием и сменой фокуса, R, предупреждение/финал, возврат управления. После переназначения проверить фактические подсказки.

При проблеме сохранить `logs/latest.log` **тестового профиля**, версию Java и описание действия. Не считать успешную macOS-сборку подтверждением работы на Linux. Текущая открытая macOS-сессия не перезапускалась: новые исправления загрузятся только при следующем запуске после сохранения и выхода пользователем.
