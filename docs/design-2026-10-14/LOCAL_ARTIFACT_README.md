# Bekhilitt 1.5.0-epic.1 — игровой срез и жизнь лагеря

Экспериментальная сюжетная модификация Minecraft в эстетике раннего Золотого века «Берсерка». Два центральных героя всей кампании — Гатс и Гриффит. В текущем реализованном срезе игрок управляет Гатсом. Первый эпизод: ранение → восстановление и разговоры → нативный бой с Гриффитом → вступление в Отряд Сокола → свободный безопасный лагерь. Следующий игровой срез: ночной рейд на склад, прикрытие тыла, совместный бой, помощь Гриффита и возвращение с однократным признанием Отрядом.

Текущий стек: **Minecraft 1.21.1 · NeoForge 21.1.219 · Epic Fight 21.17.3.1 · Java 21**. Исторические Fabric 1.0.0/1.1.0 — отдельные версии, не совместимый профиль сохранений.

## Запуск

1. Создайте отдельный профиль с указанными версиями и JVM-флагом `-Dbekhilitt.dev=true`. Официальные зависимости закреплены в `DEPENDENCIES.json`, проверяются `scripts/fetch-official-mods.py`.
2. В mods должен быть только один собственный JAR: `bekhilitt-1.5.0-epic.1.jar`. Minecraft/NeoForge/Epic Fight/worldgen JAR не входят в наш архив.
3. Создайте обычный одноразовый мир `Bekhilitt-Test*` с командами, без ценного содержимого. `/bekhilitt start disposable` запускает эпизод. Не открывайте обычные миры или сохранения 1.1.0.

Установка текущего среза (источник локального комплекта: `docs/INSTALL_GAMEPLAY_SLICE.md`; в эту публикацию не включён), первый эпизод и рейд (источник локального комплекта: `docs/INSTALL_FIRST_HAWKS_RAID.md`; в эту публикацию не включён), базовая настройка профиля (источник локального комплекта: `docs/INSTALL_EPIC_PROFILE.md`; в эту публикацию не включён).

Диалоги находятся снизу и листаются кнопками/стрелками. После END доступны `/bekhilitt camp`, разговоры по ПКМ, `/bekhilitt practice`, `/bekhilitt stop`. После вступления доступно первое поручение: разговор с Гриффитом или `/bekhilitt mission`. В безопасном лагере бой отключён. `/bekhilitt stop` возвращает исходные параметры; обычный бой вне лагеря не блокируется.

## Базовый лагерный этап 1.4 (историческая проверка)

После завершения рейда доступны три бойца с наблюдаемыми лагерными занятиями и отдельный повторяемый базовый спарринг `/bekhilitt train`. Основной игровой цикл проверен на точном production JAR в облачном Linux: настоящие попадания, блок и уклонение, безопасный возврат, повтор, остановка и сохранение/загрузка. Чистая и повторная проверки: 381 JUnit + 77 Python. Точная привязка к SHA-256 и ограничения находятся в QA 1.4 (источник локального комплекта: `docs/QA_CAMP_LIFE.md`; в эту публикацию не включён). Поставленный комплект 1.3.0-epic.1 сохранён как рабочий резерв. Новые занятия не меняют канонический результат, не выдают награды и не открывают следующую миссию.

## Сборка

Полный JDK 21. Поместите официальный Epic Fight выпуска 8175609 в `libs/` с именем, ожидаемым `build.gradle`, проверьте его по manifest. `./gradlew clean build` создаёт собственный JAR; `./gradlew runClient` использует отдельный dev-профиль. Python-тесты: `python3 -m unittest discover -s scripts -p 'test_*.py'`. Runtime QA требует отдельного запуска production JAR.

[Карта проекта](PROJECT_MAP.md), [статус](STATUS.md), [конституция](CONSTITUTION.md), [архитектура](ARCHITECTURE.md). Исторические QA-документы не доказывают проверку новых версий.

## Актуальная концепция двух героев

Собственная линия, боевой стиль, способности и развитие Гриффита обязательны для направления проекта. Возможность игры Гриффитом в заданных одиночных эпизодах утверждена, но пока не реализована. Конкретные эпизоды и интерфейс передачи управления открыты; кооператив не реализован. [Обзор](TWO_HEROES_REVIEW.md), [требования](CONSTITUTION.md), [актуальная архитектура](ARCHITECTURE.md). Эта редакция меняет только документацию отдельной рабочей копии, а не состав или QA замороженной 1.5.
