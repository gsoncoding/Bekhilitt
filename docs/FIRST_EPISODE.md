# Первый эпизод 1.1.0: одноразовый тестовый профиль

## Запуск

Minecraft 1.21.11, Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11, Java 21 (JDK для сборки). Используйте отдельный профиль и `-Dbekhilitt.dev=true`. Для разработки `./gradlew runClient` использует только `run/client` и стабильное offline-имя `BekhilittQA`: это сохраняет UUID участника между перезапусками dev-клиента. Обычный launcher использует ваш собственный аккаунт; тестовые миры разных UUID не объединяются.

1. Создайте **новый одноразовый одиночный мир**, имя `Bekhilitt-Test` или `Bekhilitt-Test-<суффикс>`, разрешите команды. Для быстрой проверки удобен Superflat без структур: высокий рельеф обычного мира может занять безопасно проверяемую область лагеря.
2. `/bekhilitt start` показывает предупреждение. `/bekhilitt start disposable` начинает новый эпизод. Если область лагеря занята, запуск отказывается заменять чужие блоки.
3. Первые ранение, доставка и восстановление — короткая постановка без управления. После пробуждения можно ходить. Разговор с Каской рядом с палаткой открывается при подходе; далее подойдите к Гриффиту возле площадки.
4. Продолжайте фиксированные страницы кнопкой UI. В единственном поединке defaults: ЛКМ — удар, удержание ПКМ — защита, R — уклонение. Привязки можно менять в настройках.
5. После 2 попаданий, успешного блока и уклонения (не раньше 20 секунд), либо по лимиту 60 секунд, появится предупреждение. Затем постановочное поражение, вступление и конец. Это технический баланс и постановка, не окончательные канонические анимации.

## Прерывание

- Escape в сцене или `/bekhilitt stop`: приостановить и вернуть исходную позицию/режим
- `/bekhilitt resume`: продолжить с начала сохранённого этапа
- `/bekhilitt status`: состояние контрольной точки
- `/bekhilitt talk`: открыть доступный разговор рядом с нужным NPC
- Перезаход восстанавливает незавершённый возврат. Уже завершённый эпизод не повторяет бой

На новом этапе сохраняется одна серверная контрольная точка. Прерванный разговор начинается сначала, незавершённый бой — с начала попытки. Завершение записывает вступление один раз. При повреждённом/неизвестном формате запуск блокируется, файл не сбрасывается. Перед ручным восстановлением резервной копии закройте мир.

## Границы кандидата

Временные модели, компактные декорации лагеря, собственный текстовый пересказ. Нет озвучки, финальных анимаций, следующего задания, кооператива или полной арки. Шейдеры/OptiFine не входят в проверенную конфигурацию. Сборка и модульные тесты не равны игровому QA; актуальный отчёт — [STATUS](STATUS.md).

Кат-сцена и диалог временно выбирают вид от первого лица, затем возвращают ваш прежний F5-режим. В свободном лагере и обычном бою выбор камеры остаётся вашим.
