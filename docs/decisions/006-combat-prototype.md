# ADR 006 — изолированный боевой стенд 1.0.0

Статус: реализован по разрешению пользователя «Давай» на технический прототип. Пользователь отдельно выбрал номер 1.0.0 и содержательные игровые итерации вместо номера на каждый фикс.

Один Fabric-проект, прежние Minecraft 1.21.11 / Java 21 / Loom 1.14.10 / Gradle 9.2.1 / Loader 0.19.5 / Fabric API 0.141.6+1.21.11. Версии закреплены. Gradle distribution проверяется SHA-256 официального сервиса. Переносимый JDK хранится вне репозитория, системная Java не меняется.

Вместо кампании — временная Session в адаптере встроенного сервера и чистый Duel, измеряющий серверные тики. Клиент посылает только намерения через Fabric payload; сервер определяет допустимость/дальность/направление и исход. S2C передаёт только состояние представления. Нет постоянного сетевого сервиса.

Временные модели — Player и ArmorStand с экипировкой. Альтернатива собственного EntityType/рендерера отложена до проверки базового боя. Стойка позволяет проверить геометрию и фазы без зависимости от готовой анимации. Это не реализация запланированного story_npc.

Старт доступен только с dev-флагом, во встроенном сервере с одним игроком; изменяется только одноразовая площадка. Прерывание возвращает режим и позицию, завершение отдельно сообщает канонический исход, не устанавливая флаги кампании. Полная crash-recovery и сохранения откладываются к P1. Defaults и ограничения — [COMBAT_PROTOTYPE](../COMBAT_PROTOTYPE.md).
