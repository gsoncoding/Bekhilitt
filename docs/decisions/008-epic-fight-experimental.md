# ADR 008: изолированная экспериментальная версия Epic Fight

Статус: реализовано для экспериментального integrated-профиля, 13 октября 2026. Фактическая приёмка — QA_EPIC_FIGHT.md. Не заменяет проверенную 1.1.0.

## Основание

Пользователь явно разрешил перенос экспериментальной сборки на Minecraft 1.21.1,
NeoForge 21.1.219 и официальный Epic Fight 21.17.3.1 на облачном компьютере.
Приоритеты: настоящая боевая основа, перенос существующего первого эпизода,
сохранения/повторные запуски и локальный сервер. Важны цельное мрачное фэнтези
раннего Золотого века, генерация окружения и качество законченного результата.
Новая кампания, лаунчер, VPS и публикация изменений в этот этап не входят.

## Границы

- Epic Fight единолично владеет обычными атаками, guard, dodge, анимациями и сетью боя.
  Старые ControlPayload и геометрический Duel не управляют новым runtime.
- Чистый Duel остаётся историческим тестируемым ядром 1.1.0. Новая попытка боя
  имеет отдельную серверную идентичность; старое/чужое завершение не принимается.
- Клиент владеет только представлением и revision-checked намерением продолжить
  диалог. Камера и временные блокировки возвращаются при stop/disconnect.
- Ввод Epic Fight: R переключает боевой режим; стандартное уклонение Left Alt.
  HUD берёт фактические пользовательские назначения, глобальные настройки не меняются.
- Оппонент использует поддержанный Epic Fight humanoid AI. Временная модель
  отмечается как placeholder; это не финальная внешность Гриффита.
- Канонический исход сохраняется: один поединок, поражение, вступление, END.
  Освоение управления не открывает новую главу и не изменяет исход.
- Исходная 1.1.0 и её миры не перезаписываются. Новая версия предназначена для
  отдельного явно названного disposable тестового мира.
- Dedicated test требует отдельного opt-in и одного владельца; кооператив и
  публичный сервер не объявляются поддержанными. EULA не принимается автоматически.
- Integrated recovery проверяет owner в level.dat; dedicated recovery проверяет
  только соответствующий UUID.dat. Lease сохраняется до проверки реальных bytes.

## Окружение

Свой bounded vanilla-block план лагеря, следов войны и руин получает стабильные
сюжетные anchors и seeded variation. Preflight проверяет весь объём до записи.
Это не универсальный генератор мира. Дополнительные официальные worldgen mods
оцениваются отдельно и включаются только после проверки нового профиля.

## Зависимость и права

Официальная закреплённая версия:
https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod/files/8175609

Epic Fight указывает Code GPL-3.0, Assets All Rights Reserved и разрешает модпаки
и addons, ссылающиеся на зависимость. Мы не копируем движок или animation assets.
Официальный jar используется для локальной разработки/QA; пользовательский
комплект содержит нашу сборку и manifest/инструкцию отдельной установки зависимости.
Source jar 8175610 применяется только как API reference и не входит в наш source ZIP.
Demolition Leap/Meteor Slam — встроенные возможности зависимости; существование
этих skills не означает их автоматическое каноническое открытие в первом эпизоде.

## Проверка

Компиляция, unit tests, запуск с настоящим EF и реальный игровой проход — разные
ступени. Успех unit tests не является подтверждением playable runtime. Итоговый
QA фиксирует фактически пройденные сценарии и отдельно оставшиеся ограничения.
