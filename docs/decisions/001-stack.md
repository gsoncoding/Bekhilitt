# ADR 001 Технический стек для первого прототипа

Статус: **проверено сборкой технического прототипа 1.0.0**. Проверка официальных источников: 12 октября 2026 года. Пользователь утвердил Minecraft 1.21.11; Fabric выбран как инженерное решение. Выполнен успешный build с 9 тестами; результаты игрового запуска отдельно в STATUS.

## Выбор и свидетельства

Предлагается Java и Fabric: достаточно одного мода с Fabric API, без обязательных внешних библиотек анимации, диалогов, UI или шейдеров. Меньше зависимостей — меньше непроверенных портов. Это инженерный выбор, а не сравнение производительности загрузчиков.

## Границы проверки и следующий шаг

Поддержка целевой игры экосистемой подтверждена. Комбинация артефактов разрешена и скомпилирована с переносимым JDK 21.0.12.1; 9 JUnit-тестов пройдены. Это не доказывает игровое поведение; отдельные результаты запуска — в [STATUS](../STATUS.md). Таблица кандидатов выше сохраняет исходные свидетельства выбора.

На этапе P0 из [плана](../PROTOTYPE_PLAN.md): закрепить версии без SNAPSHOT и динамических диапазонов, добавить wrapper с проверкой контрольной суммы, проверить JDK 21, собрать минимальный мод, открыть тестовый мир и запустить выделенный сервер. Записать команды и результат только после выполнения. При несовместимости менять кандидат Loom/Gradle с записью причины; не менять Minecraft молча.

## Альтернативы и последствия

NeoForge остаётся альтернативой при появлении необходимой зависимости; его совместимость здесь не исследована. Одни datapack и ресурспак не выбраны как основа из-за предполагаемого управления боем, сценами и интерфейсом. Сторонняя библиотека анимации откладывается до доказанной потребности и проверки её версии для 1.21.11. Fabric API — единственная предложенная дополнительная библиотека исполнения первого среза. Не считать поддержку сторонних модов проверенной.
