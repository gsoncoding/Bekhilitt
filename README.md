# Bekhilitt

Гатс остаётся игровым героем; [Гриффит](docs/story/GRIFFITH.md) проектируется как второй главный персонаж с собственной канонической линией, памятью и осмысленным поведением.

Предусмотрены характеристики персонажей, ограниченное каноном развитие Гатса и апостолы-боссы. [Кандидаты и ограничения встреч](docs/story/BOSSES.md) требуют дальнейшей сверки перед реализацией.

Сюжетная модификация Minecraft 1.21.11 по мотивам аниме «Берсерк» 1997 года. Основная кампания посвящена Золотому веку; игрок — Гатс, начало — встреча с отрядом Сокола.

Сейчас здесь только проектная документация. Кода, сборки, ресурспака и игрового прототипа нет. Команд запуска пока нет. Документированная архитектура — предложение для реализации, а не описание работающего мода.

Первый играбельный результат утверждён: короткий эпизод за Гатса — знакомство с Отрядом Сокола, один разговор с Гриффитом и один играбельный поединок с ним. Игрок учится только удару, защите и уклонению; Гриффит завершает бой постановочным приёмом. Эпизод заканчивается каноническим поражением и вступлением Гатса в отряд. На первых стадиях диалог фиксированный, без выбора, меняющего историю. Первая версия одиночная за Гатса; кооператив отложен на будущее, не отменён. Предшествующие события сохраняются как контекст; отдельная тренировка и новые миссии не добавляются. [План и приёмка](docs/PROTOTYPE_PLAN.md).
