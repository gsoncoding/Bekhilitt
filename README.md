# Bekhilitt

Гатс остаётся игровым героем; [Гриффит](docs/story/GRIFFITH.md) проектируется как второй главный персонаж с собственной канонической линией, памятью и осмысленным поведением.

Предусмотрены характеристики персонажей, ограниченное каноном развитие Гатса и апостолы-боссы. [Кандидаты и ограничения встреч](docs/story/BOSSES.md) требуют дальнейшей сверки перед реализацией.

Сюжетная модификация Minecraft 1.21.11 по мотивам аниме «Берсерк» 1997 года. Основная кампания посвящена Золотому веку; игрок — Гатс, начало — встреча с отрядом Сокола.

Добавлен технический боевой прототип **1.0.0**: Fabric-проект, серверные правила дуэли, временные модели и изолированная площадка. Запуск: `./scripts/dev.sh`. Полная сюжетная архитектура остаётся планом; фактические результаты проверки перечислены в [STATUS](docs/STATUS.md).

Первый играбельный результат утверждён: короткий эпизод за Гатса — первое ранение Гатса Гриффитом, доставка в лагерь без сознания, восстановление/пробуждение и разговор с Каской, затем разговор с Гриффитом и один полноценный играбельный поединок с ним. Игрок учится только удару, защите и уклонению; Гриффит завершает бой постановочным приёмом. Эпизод заканчивается каноническим поражением и вступлением Гатса в отряд. На первых стадиях диалог фиксированный, без выбора, меняющего историю. Первая версия одиночная за Гатса; кооператив отложен на будущее, не отменён. Сцена восстановления с Каской включена; первое столкновение и ранение показаны короткой кат-сценой без управления; игрок получает управление после пробуждения в лагере. Второй полноценный бой, отдельная тренировка и новые миссии не добавляются. [План и приёмка](docs/PROTOTYPE_PLAN.md).
