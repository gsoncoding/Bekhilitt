# Bekhilitt 1.2.0-epic.4

Экспериментальная сюжетная модификация Minecraft в эстетике раннего Золотого века «Берсерка». Игрок — Гатс. Первый эпизод: ранение → восстановление и разговоры → нативный бой с Гриффитом → вступление в Отряд Сокола → свободный безопасный лагерь.

Текущий стек: **Minecraft 1.21.1 · NeoForge 21.1.219 · Epic Fight 21.17.3.1 · Java 21**. Исторические Fabric 1.0.0/1.1.0 — отдельные версии, не совместимый профиль сохранений.

## Запуск

1. Создайте отдельный профиль с указанными версиями и JVM-флагом `-Dbekhilitt.dev=true`. Официальные зависимости закреплены в `DEPENDENCIES.json`, проверяются `scripts/fetch-official-mods.py`.
2. В mods должен быть только один собственный JAR: `bekhilitt-1.2.0-epic.4.jar`. Minecraft/NeoForge/Epic Fight/worldgen JAR не входят в наш архив.
3. Создайте обычный одноразовый мир `Bekhilitt-Test*` с командами, без ценного содержимого. `/bekhilitt start disposable` запускает эпизод. Не открывайте обычные миры или сохранения 1.1.0.

[Полная установка и управление](docs/INSTALL_CAMP_SAFETY.md), [базовая настройка профиля](docs/INSTALL_EPIC_PROFILE.md).

Диалоги находятся снизу и листаются кнопками/стрелками. После END доступны `/bekhilitt camp`, разговоры по ПКМ, `/bekhilitt practice`, `/bekhilitt stop`. В безопасном лагере бой отключён. `/bekhilitt stop` возвращает исходные параметры; обычный бой вне лагеря не блокируется.

## Сборка

Полный JDK 21. Поместите официальный Epic Fight выпуска 8175609 в `libs/` с именем, ожидаемым `build.gradle`, проверьте его по manifest. `./gradlew clean build` создаёт собственный JAR; `./gradlew runClient` использует отдельный dev-профиль. Python-тесты: `python3 -m unittest discover -s scripts -p 'test_*.py'`. Runtime QA требует отдельного запуска production JAR.
